# ===========================================================================
# Setting up the conda environment
# ===========================================================================
#
# Run these in a terminal (Anaconda Prompt, or any terminal where conda works),
# from this project's folder.
#
# 1. Create the environment, named "dramatizer", with Python 3.10:
#
#        conda create -n dramatizer python=3.10 -y
#
#    To keep it on another drive, give a path instead of a name:
#
#        conda create -p D:/envs/dramatizer python=3.10 -y
#
# 2. Step into the environment. Your prompt now starts with (dramatizer),
#    and "python" and "pip" mean this environment's copies:
#
#        conda activate dramatizer
#        conda activate D:/envs/dramatizer        (if you created it with -p)
#
# 3. Install the one package that will not build on its own. openai-whisper
#    needs the old setuptools while it builds, so install that first and
#    build whisper with it:
#
#        pip install "setuptools<81" wheel
#        pip install --no-build-isolation openai-whisper==20231117
#
# 3b. Resemblyzer asks for "webrtcvad", which needs a C++ compiler to build
#    on Windows. Install it without its dependencies, because
#    webrtcvad-wheels (in this file) already provides what it needs:
#
#        pip install --no-deps resemblyzer==0.1.4
#
# 4. Install everything else:
#
#        pip install -r requirements.txt
#
# 5. Check that the GPU is visible (should print True):
#
#        python -c "import torch; print(torch.cuda.is_available())"
#
# 6. Step out of the environment when you are done:
#
#        conda deactivate
#
# Other useful commands:
#
#        conda env list                       every environment on this machine
#        conda env remove -n dramatizer       delete the environment, to start over
#
# The CosyVoice checkout and the model weights are not Python packages and are
# not installed by pip. See README.md and set their paths in .env.

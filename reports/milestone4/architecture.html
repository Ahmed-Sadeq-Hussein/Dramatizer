Dramatizer serving architecture

How a visitor reaches the voice-cloning site, what runs on the one GPU, and how a new version is checked before it takes over. Everything runs in Docker on a single Windows PC with an RTX 3080.

The request path

A visitor on app.dramatizer.dev gets Cloudflare's trusted certificate. Cloudflare's tunnel reaches the front door inside Docker, and the front door passes the encrypted bytes on to whichever slot is live. Clients that pin the site's own certificate connect on port 5005 and see that certificate unchanged.

The release path

A version reaches visitors only after it has passed the tests on GitHub and five checks against the real running container. If a check fails, the front door never moves and the previous version starts again.
